# crates/dxview/src/horizon.rs says what each option does.
#
# Change one thing per run, and play the same route each time: 30 s in the main menu, New Game, then on
# Liberty Island 30 s standing at the start and 60 s walking towards the statue. Copy log.txt and cpu-profile.txt
# off after each launch: the next one rewrites them.

# The Performance settings (Settings > Enhancements > Performance: Anti-Aliasing, HDR Rendering, Lean Rendering,
# Lean Updates) start lean on the Switch; change them in the game, or in settings.txt beside the NRO. The FPS Counter
# is there too (frames a second and the frame time, top right).

# Profiling, on in every run so they compare: the game's report every 5 s in log.txt (per-system and per-pass
